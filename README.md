# PrimeEstate — Premium Real Estate

Marketing landing page for a premium real-estate brand: featured listings,
editorial article cards, a video section and an FAQ.

## Sections

- Hero and site header
- Featured article + article card grid
- Video section
- FAQ accordion
- Call to action

## Stack

React · TypeScript · Vite · Tailwind CSS

## Running locally

**Prerequisites:** Node.js 18+

```bash
npm install
npm run dev
```

| Command | What it does |
|---|---|
| `npm run dev` | Vite dev server |
| `npm run build` | Production build to `dist/` |
| `npm run preview` | Serve the production build |
| `npm run lint` | ESLint |
